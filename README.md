# e-Tickets (Em Desenvolvimento)

Badge em Desenvolvimento

Bem-vindo ao repositório do meu projeto de Sistema de Tickets! Este é um projeto de portfólio que estou desenvolvendo para aplicar e demonstrar minhas habilidades em desenvolvimento de software. A ideia é criar um sistema completo para gerenciamento de chamados, desde a abertura até a solução.

Importante:  Este projeto ainda está em fase de desenvolvimento. Funcionalidades podem ser adicionadas, removidas ou modificadas. Fique à vontade para acompanhar o progresso!

🎯 Sobre o Projeto
O objetivo deste sistema é oferecer uma plataforma onde usuários possam criar contas, abrir tickets de suporte e acompanhar o status de suas solicitações. Do outro lado, técnicos e administradores terão as ferramentas necessárias para gerenciar esses tickets, atribuir responsabilidades e se comunicar com os usuários.

✨ Funcionalidades Planejadas
Aqui está um resumo do que estou planejando implementar:

## Autenticação e Usuários

 Cadastro de Usuário: Novos usuários poderão se cadastrar na plataforma.
 
 Login de Usuário: Sistema de autenticação seguro.
 
## Perfis de Acesso:
Usuário Comum: Abre e acompanha seus próprios tickets.

Técnico: Atende aos tickets que lhe são atribuídos.

Administrador: Gerencia usuários, tickets e configurações do sistema.


## Gerenciamento de Tickets
 Criação de Ticket: Usuários poderão abrir novos chamados, detalhando o problema.
 
### Visualização de Tickets:
Usuários verão uma lista de seus tickets abertos e fechados.

Técnicos e Admins terão uma visão geral de todos os tickets.

 Atribuição de Tickets: Administradores poderão atribuir tickets a técnicos específicos.
 
 Atualização de Status: O status de um ticket poderá ser alterado (ex: Aberto, Em Andamento, Pendente, Resolvido).
 
 Adição de Comentários: Usuários e técnicos poderão adicionar comentários para interagir dentro de um ticket.
 
 Encerramento de Ticket: Apenas técnicos e administradores poderão encerrar um ticket após a solução.
 
## Interface e Experiência
 Dashboard Intuitivo: Painéis diferentes para cada tipo de perfil, mostrando as informações mais relevantes.
 Design Responsivo: A interface se adaptará a diferentes tamanhos de tela (desktop, tablet e mobile).

🛠️ Tecnologias

Frontend: Vue.js

Backend:  Java (Spring)

Banco de Dados: PostgreSQL

Autenticação: JWT e OAuth

Fluxo: n8n (implementação futura ) 

ChatBot: ChatGPT (implementação futura )
